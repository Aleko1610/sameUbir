# Gestor Semanal de Viajes V1.5

Permite generar un único cronograma semanal por cliente.

Funciones:
- Mismo viaje de lunes a viernes.
- Viajes personalizados por día.
- Ida y vuelta con horarios, recorridos y pasajeros distintos.
- Cálculo de combustible, costos y ganancia.
- Exportación a PNG.

Uso: abrir index.html en el navegador.
